# Portfolio — Nanthaphat Phetsanghan (lsupwp)

Personal portfolio website for a cybersecurity student & security developer.

Built with **Next.js 16** (App Router) + **React 19** + **TypeScript** +
**Tailwind CSS v4** + **daisyUI 5** + **Framer Motion**.

## Structure

```
.
└── app/        # Next.js application (source, config, dependencies)
```

The Next.js app lives in the `app/` directory. See [`app/README.md`](app/README.md)
for full documentation (tech stack, project structure, theming, content).

## Quick Start

```bash
cd app
npm install
npm run dev        # http://localhost:3000
```

Production:

```bash
cd app
npm run build
npm run start
```
